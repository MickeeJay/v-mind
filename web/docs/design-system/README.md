# V-Mind Design System

This folder documents the foundational UI primitives used in the V-Mind App Router frontend.

## Principles

- Trust-first visual language with clear hierarchy and predictable controls.
- Bitcoin-native accenting with semantic safety colors for operational states.
- Accessible keyboard and screen-reader support inherited from Radix and shadcn primitives.
